# StructuredJson 2.0 design

Implement the user-authorized audit remediation in the existing checkout. Release 2.0.0 targets .NET 8, 9, 10 and 11 RC1. Remove legacy netstandard support as a documented major-version change. Do not publish externally until the finished artifact is reviewed.

Keep the public facade and use a strict escaped property/index tokenizer, a normalized private dictionary/list tree, and lossless cloned JsonElement number tokens. Object root is required. Support repeated array indices and empty/literal property names (\\ escapes reserved characters; \e denotes an empty property). Set normalizes before mutation and constructs only the changed path, so rejection is atomic and unrelated branches need not be copied. Reads return detached snapshots. Defaults: invariant conversion, type-conflict exceptions, depth 128, path length 4096, array length 100000, total node count 1000000. Options are validated and snapshotted. JSON settings are shared by input and typed conversion; ToJson formatting options may be supplied without bypassing structural limits.

Retain Get<T> default-on-conversion-failure for compatibility; add TryGet<T> and GetRequired<T>. Preserve nulls and empty containers in ListPaths. Synchronize all tree access. Input cycles/duplicate properties/nonfinite numbers are rejected before mutation. Do not claim Native AOT support; document the reflection serializer boundary.

Fix CI for all targets and all PRs, Sonar begin/build/end, immutable version-tag publication, least privileges, package/example smoke testing and dependency update coverage. Remove private IDE session files, update docs and add a real benchmark. Keep historical audit evidence clearly labeled as v1 behavior.
